## Hard startup contracts (the app enforces these — fail-closed by design)

1. **SECRET_KEY**: refuses known-insecure defaults and keys < 32 chars (`app/core/auth.py:validate_secret_key`).
   The fleet supervisor injects a generated 48-char key. For local runs:
   `set SECRET_KEY=<48+ random chars>`
2. **OMNIROUTE_BASE_URL must be exactly `http://127.0.0.1:8190/v1`** (`app/services/nim_client.py:configured_omniroute_base_url`).
   Any other URL (old `localhost:20128`, the Worker URL, anything) is rejected at startup — the
   consumer boundary is the local session-pool shim, never a direct gateway URL.
   => The fleet supervisor runs `session_pool_shim.py` on 127.0.0.1:8190 (serves `/v1/models`
   with `session-pool/auto`, proxies the rest to the permanent door's `/v1`).
3. `INFERENCE_PROVIDER=omniroute` (default; mandatory in production APP_ENV).
